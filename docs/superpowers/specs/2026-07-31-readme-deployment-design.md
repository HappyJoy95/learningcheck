# 运维部署 README 设计

## 目标

将项目 README 改写为面向 Windows 运维人员的从零部署手册。读者无需了解项目代码，但应具备 Windows 管理员权限，并能安装 Python、ADB 和安卓模拟器。

## 范围

README 覆盖：

1. 项目用途、运行边界与安全注意事项。
2. Windows、Python、ADB、安卓模拟器和应用的部署前置条件。
3. 项目文件、Python 依赖、配置文件和本地账号 CSV 的配置步骤。
4. 可选的邮件账号源、邮件通知和 HTTP 报告上传配置。
5. ADB 连通性检查、首次手动运行、输出和报告验收。
6. Windows 任务计划程序的安装、时间调整、手动触发与停用。
7. 日常运维说明与按现有行为编写的故障排查。

README 不包含真实账号、密码、授权码、服务器地址或接口密钥；示例仅使用占位值。

## 文档结构

1. 标题、用途、系统边界。
2. 部署前准备。
3. 从零部署（按顺序编号，每一步提供验收结果）。
4. 配置参考与账号 CSV 格式。
5. 首次验收和报告说明。
6. 定时运行。
7. 日常维护与安全。
8. 故障排查。

## 事实约束

- 项目使用 `main.py` 作为手动入口，`run.bat` 为 Windows 包装脚本。
- 账号主文件位于 `data/learning_check/input/accounts.csv`，且 `execute_flag=1` 的记录才会执行；成功完成的账号会被写为 `0`，每周首次执行时程序会重置为 `1`。
- `schedule_setup.ps1` 会创建名为 `LearningCheck-Auto` 的任务，脚本当前固定每天 08:00 运行；`config/config.yaml` 不控制该脚本的触发时间。
- 输出目录为 `data/learning_check/<运行时间>/`，项目会在成功运行后清理未压缩截图，但会保留报告 ZIP。
- 上传接口使用 HTTP；README 将明确提示仅应在可信网络或经过额外保护的环境中启用。

## 验收标准

一名 Windows 运维人员可根据 README 独立完成部署，验证 ADB 设备、手动生成一份报告，并创建或管理定时任务；出现常见故障时能先完成定位。
